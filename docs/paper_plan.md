# Paper Plan

Working title:

**Verifiable Resource Certificates for Public Reversible Arithmetic Blocks in Quantum ECDLP**

Core idea:

Recent quantum-ECDLP work has split into multiple disclosure styles. Some works publish explicit public arithmetic circuits, while others use zero-knowledge attestation to support resource claims while withholding sensitive circuits. This paper proposes a reusable certificate format for public reversible arithmetic blocks, beginning with modular inversion over prime fields.
